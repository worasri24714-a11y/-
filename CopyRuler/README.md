# ไม้บรรทัดลอกงาน (Copy Ruler)

แอป Android ช่วยลอกงานจากต้นฉบับลงกระดาษโดยไม่หลงบรรทัด
แอปไฮไลต์ท่อนที่กำลังลอกไว้ตลอด พอเขียนเสร็จก็กด “ลอกเสร็จ ถัดไป” (หรือกดปุ่มลดเสียง) แถบไฮไลต์จะเลื่อนไปท่อนถัดไปให้ทันที
เงยหน้ากลับมาดูเมื่อไรก็เจอตำแหน่งเดิมเสมอ

ทำงานแบบออฟไลน์ทั้งหมด หน้าจอภาษาไทยทั้งแอป

## ความสามารถ

**โหมดข้อความ**
- วางหรือพิมพ์ต้นฉบับ แล้วกด “เริ่มลอก”
- ท่อนปัจจุบันมีพื้นเหลืองแบบปากกาเน้นข้อความ ท่อนที่ลอกแล้วเป็นสีจาง ท่อนที่ยังไม่ลอกเป็นสีปกติ
- ท่อนปัจจุบันเลื่อนขึ้นมาอยู่ราว 30% จากขอบบนจอโดยอัตโนมัติ
- เลือกเลื่อน “ทีละบรรทัด” หรือ “ทีละวลี” ได้ โหมดวลีตัดตามช่องว่างและเครื่องหมายวรรคตอน แล้วรวมท่อนสั้นให้ยาวอย่างน้อยราว 18 ตัวอักษร
  ใช้กับภาษาไทยได้ (ภาษาไทยเว้นวรรคระหว่างวลี) และช่วงภาษาไทยที่ยาวมากโดยไม่มีช่องว่างจะถูกตัดตามขอบเขตคำ
- ปรับขนาดตัวอักษรได้ 16–34sp แตะท่อนไหนก็กระโดดไปท่อนนั้นได้ มีเลขท่อน (เช่น 5 / 42) และแถบความคืบหน้า

**โหมดรูปถ่าย**
- ถ่ายรูปด้วยกล้อง หรือเลือกรูปจากคลังภาพ (Photo Picker) แอปคัดลอกรูปเก็บไว้ในพื้นที่ของแอปเอง ปิดแล้วเปิดใหม่รูปก็ยังอยู่
- รูปแสดงเต็มความกว้างจอ เลื่อนขึ้นลงได้ และถ่างสองนิ้วเพื่อซูมได้
- แถบไฮไลต์สีเหลืองวางบนบรรทัดที่กำลังลอก ส่วนเหนือและใต้แถบมืดลง
- ปรับความสูงแถบได้ด้วย slider (คิดเป็น % ของความสูงรูป) แตะที่รูปเพื่อย้ายแถบ หรือลากแถบได้โดยตรง
- “ถัดไป” เลื่อนแถบลงหนึ่งช่องและเลื่อนรูปตามให้แถบอยู่ในจอเสมอ
- ปุ่ม “แปลงรูปเป็นข้อความ” ใช้ ML Kit แบบในเครื่อง **ซึ่งอ่านได้เฉพาะอักษรละติน (อังกฤษ ตัวเลข) ยังอ่านภาษาไทยไม่ได้**
  แอปแจ้งข้อจำกัดนี้ตรงๆ ในหน้าผลลัพธ์ แล้วให้เลือกส่งข้อความที่อ่านได้ไปสร้างเอกสารในโหมดข้อความ

**ใช้ร่วมกันทั้งสองโหมด**
- ปุ่มใหญ่ด้านล่าง “↑ ย้อน” และ “ลอกเสร็จ ถัดไป ↓” สูง 72dp กดได้โดยไม่ต้องมอง
- ปุ่มลดเสียง = ถัดไป, ปุ่มเพิ่มเสียง = ย้อน (ทำงานเฉพาะหน้าลอกงาน ปิดได้ในหน้าตั้งค่า)
- สั่นเบาๆ ทุกครั้งที่เลื่อน (ปิดได้) และหน้าจอไม่ดับระหว่างอยู่หน้าลอกงาน
- เก็บได้หลายเอกสาร จำตำแหน่งล่าสุดของแต่ละเอกสาร เปลี่ยนชื่อ แก้ไข และลบได้ (ถามยืนยันก่อนลบ)
- ธีม “กระดาษกับปากกาเน้นข้อความ” รองรับโหมดมืดตามระบบ (หรือเลือกเองในหน้าตั้งค่า) ใช้ฟอนต์ IBM Plex Sans Thai
- ครั้งแรกที่เปิดแอปจะมีเอกสารตัวอย่างเรื่อง “พันธะเคมี” ไว้ให้ลองกด

## ไฟล์ APK สำเร็จรูป

ถ้าไม่อยาก build เอง ติดตั้งไฟล์ [`release/CopyRuler-1.0.apk`](release/CopyRuler-1.0.apk) ได้เลย
(Android 8.0 ขึ้นไป ขนาดราว 14 MB, SHA-256 `9282fbb83422874f38f09e8fdc4eb9f1678a328ee4acb645466f38da983b980c`)

- ส่งไฟล์เข้ามือถือ แตะเปิด แล้วอนุญาต “ติดตั้งแอปที่ไม่รู้จัก” สำหรับแอปที่ใช้เปิดไฟล์
- ไฟล์นี้ **ไม่มีปุ่ม “แปลงรูปเป็นข้อความ”** เพราะเครื่องที่ใช้ build เข้าถึงไฟล์ ML Kit ของ Google ไม่ได้ ฟีเจอร์อื่นครบทุกอย่าง
  ถ้าต้องการฟีเจอร์นี้ ให้ build เองจาก Android Studio ตามขั้นตอนด้านล่าง
- ไฟล์นี้เซ็นด้วยคีย์คนละตัวกับที่ Android Studio ใช้ ถ้าจะติดตั้งเวอร์ชันที่ build เองทับ ให้ถอนการติดตั้งตัวเดิมก่อน (ข้อมูลในแอปจะหายไปด้วย)

## สิ่งที่ต้องมี

- **Android Studio รุ่นล่าสุด** ที่รองรับ Android Gradle Plugin 9.2 ขึ้นไป (ดาวน์โหลดที่ <https://developer.android.com/studio>)
- Android SDK Platform 37 (Android Studio จะเสนอให้ติดตั้งให้เองตอน sync ถ้ายังไม่มี)
- JDK 17 ขึ้นไป (Android Studio มี JDK มาให้แล้ว)
- ต่ออินเทอร์เน็ตในการ build ครั้งแรก เพื่อดาวน์โหลด Gradle และไลบรารี ส่วนตัวแอปใช้งานแบบออฟไลน์ได้

## วิธีรันใน Android Studio

1. เปิด Android Studio แล้วเลือก **File → Open…** จากนั้นเลือกโฟลเดอร์ `CopyRuler`
2. รอ Gradle sync จนเสร็จ (ครั้งแรกอาจใช้เวลาหลายนาที)
3. เปิดโหมดนักพัฒนาและ **USB debugging** บนมือถือ แล้วต่อสาย USB (หรือใช้ emulator ใน Device Manager)
4. เลือกอุปกรณ์ที่แถบด้านบน แล้วกด **Run ▶** (Shift+F10)

## วิธีสร้างไฟล์ APK ติดตั้งบนมือถือ

### ทางที่ 1: ผ่าน Android Studio

เลือกเมนู **Build → Generate App Bundles or APKs → Generate APKs**
เสร็จแล้วกดลิงก์ **locate** ในแจ้งเตือนมุมขวาล่าง จะได้ไฟล์

```
CopyRuler/app/build/outputs/apk/debug/app-debug.apk
```

### ทางที่ 2: ผ่าน command line

เปิด terminal ที่โฟลเดอร์ `CopyRuler`

```bash
# macOS / Linux
./gradlew assembleDebug

# Windows
gradlew.bat assembleDebug
```

ถ้าไม่ได้ build ผ่าน Android Studio มาก่อน ให้บอกตำแหน่ง Android SDK ก่อน ด้วยตัวแปร `ANDROID_HOME`
หรือสร้างไฟล์ `local.properties` ที่มีบรรทัด `sdk.dir=/path/to/Android/sdk`

### ติดตั้งลงมือถือ

- **ผ่านสาย USB:** `adb install -r app/build/outputs/apk/debug/app-debug.apk`
- **ไม่ใช้สาย:** ส่งไฟล์ `app-debug.apk` เข้ามือถือ (เช่น ทาง LINE, Google Drive หรือสาย USB) แล้วแตะเปิดไฟล์
  ระบบจะถามให้อนุญาต “ติดตั้งแอปที่ไม่รู้จัก” สำหรับแอปที่ใช้เปิดไฟล์ ให้กดอนุญาตแล้วติดตั้ง

### APK แบบ release (ไฟล์เล็กกว่า)

```bash
./gradlew assembleRelease
```

ได้ไฟล์ `app/build/outputs/apk/release/app-release.apk` ซึ่งย่อโค้ดด้วย R8 แล้ว
เพื่อความสะดวก ไฟล์นี้เซ็นด้วย debug key จึงติดตั้งได้ทันที
ถ้าจะเผยแพร่บน Google Play ต้องสร้าง keystore ของตัวเองแล้วตั้ง `signingConfig` ใน `app/build.gradle.kts` แทน

## รัน unit test

```bash
./gradlew testDebugUnitTest
```

มีเทสต์ของฟังก์ชันตัดท่อน (ทีละบรรทัด/ทีละวลี) ทั้งข้อความไทยและอังกฤษ รวมถึงการคำนวณแถบไฮไลต์บนรูป
อยู่ใน `app/src/test/java/app/copyruler/ruler/`

## โครงสร้างโค้ด

สถาปัตยกรรม MVVM: หน้าจอแต่ละหน้าเป็น Composable ที่อ่าน `StateFlow` จาก ViewModel ของตัวเอง

```
app/src/main/java/app/copyruler/
├── CopyRulerApp.kt / AppContainer.kt   Application และตัวรวม dependency
├── MainActivity.kt                     ดักปุ่มปรับเสียง (onKeyDown) ตั้งธีมและ edge-to-edge
├── ruler/
│   ├── Segmenter.kt                    ตัดข้อความเป็นท่อน ทีละบรรทัด/ทีละวลี (Kotlin ล้วน มีเทสต์)
│   └── ImageBand.kt                    คำนวณตำแหน่งแถบไฮไลต์บนรูป
├── data/
│   ├── DocumentEntity.kt, DocumentDao.kt, AppDatabase.kt   Room (พร้อมเอกสารตัวอย่างตอนสร้างฐานข้อมูล)
│   ├── DocumentRepository.kt           บันทึกตำแหน่งตามลำดับผ่านคิวเดียว
│   ├── ImageStore.kt                   คัดลอก/หมุน/ย่อรูปเก็บในพื้นที่ภายในแอป
│   └── SettingsRepository.kt           DataStore สำหรับการตั้งค่า
├── ocr/TextRecognizerService.kt        ML Kit Text Recognition (ในเครื่อง)
└── ui/
    ├── CopyRulerNavHost.kt             Navigation: รายการเอกสาร → แก้ไขข้อความ → ลอกงาน, ตั้งค่า
    ├── list/                           หน้ารายการเอกสาร + สร้างใหม่ (ข้อความ/กล้อง/คลังภาพ)
    ├── editor/                         หน้าแก้ไขข้อความ
    ├── copy/                           หน้าลอกงาน: TextRuler (ข้อความ), ImageRuler (รูป), ปุ่มควบคุม
    ├── settings/                       หน้าตั้งค่า
    ├── common/                         สั่น, จอไม่ดับ, ปุ่มเสียง, วันที่แบบไทย
    └── theme/                          สี ฟอนต์ และธีม
```

## หมายเหตุ

- **สิทธิ์ที่ขอ:** กล้อง (ขอตอนกด “ถ่ายรูปต้นฉบับ” เท่านั้น) และการสั่น ตัวแอปไม่ได้ขอสิทธิ์อินเทอร์เน็ตเอง
  แต่ไลบรารีของ Google ที่ ML Kit ใช้อาจเพิ่มสิทธิ์เครือข่ายเข้ามาใน manifest ตอน build ทั้งนี้ทุกฟีเจอร์ทำงานได้โดยไม่ต่ออินเทอร์เน็ต
- **ฟอนต์:** IBM Plex Sans Thai ฝังอยู่ใน `app/src/main/res/font` ใช้สัญญาอนุญาต SIL Open Font License 1.1
  (ดู `third_party/IBM_Plex_Sans_Thai_OFL.txt`)
- **ถ้า sync ไม่ผ่าน:**
  - `Failed to find target android-37`: เปิด **Tools → SDK Manager** แล้วติดตั้ง Android SDK Platform 37
  - เรื่องเวอร์ชัน Java: ไปที่ **Settings → Build, Execution, Deployment → Build Tools → Gradle** แล้วตั้ง *Gradle JDK* เป็น JDK 17 หรือ 21
  - Android Studio รุ่นเก่าอาจไม่รู้จัก AGP 9.2: อัปเดต Android Studio เป็นรุ่นล่าสุด
