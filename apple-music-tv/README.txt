Apple Music TV Mode — ส่วนขยาย Chrome / Edge (Manifest V3)
==============================================================

ครอบเว็บ music.apple.com ให้มีหน้า Now Playing เต็มจอแบบ Apple TV พร้อมเนื้อเพลงซิงก์
เหมาะกับ PC ที่ต่อ HDMI เข้าทีวีแล้วดูจากโซฟา (ระยะ 2–3 เมตร)
ไม่ใช้ Apple Music API และไม่ต้องใช้ developer token — อ่านข้อมูลจากเว็บที่คุณเปิดอยู่เท่านั้น


วิธีติดตั้ง (Load unpacked)
---------------------------
Chrome
  1. เปิด chrome://extensions
  2. เปิดสวิตช์ "Developer mode" มุมขวาบน
  3. กด "Load unpacked" แล้วเลือกโฟลเดอร์ apple-music-tv (โฟลเดอร์ที่มี manifest.json)

Microsoft Edge
  1. เปิด edge://extensions
  2. เปิด "Developer mode" (แถบซ้าย/ล่าง)
  3. กด "Load unpacked" แล้วเลือกโฟลเดอร์ apple-music-tv

จากนั้นเปิด (หรือ reload) https://music.apple.com แล้วล็อกอินตามปกติ
ถ้าได้ไฟล์ .zip มา ให้แตกไฟล์ก่อน แล้วเลือกโฟลเดอร์ที่แตกออกมา


คีย์ลัด
-------
หน้าเว็บปกติ
  T                 เปิดโหมดทีวี (หรือกดปุ่มลอย "TV Mode" มุมขวาล่าง)
  Z                 สลับขนาดหน้าเว็บ 100% → 115% → 130% → 150% (จำค่าไว้)

โหมดทีวี (Now Playing)
  Space / Enter / K เล่น / หยุด
  ← / →             ถอยหลัง / เดินหน้า 10 วินาที
  Shift+→ หรือ N    เพลงถัดไป
  Shift+← หรือ P    เพลงก่อนหน้า (ถ้าเล่นเกิน 3 วินาที จะกลับไปต้นเพลงก่อน)
  L                 แสดง / ซ่อนเนื้อเพลง
  F                 เต็มจอ (หรือดับเบิลคลิกที่พื้นหลัง)
  Esc / T / Backspace  ปิดโหมดทีวี
  Media keys        เล่น/หยุด, ถัดไป, ก่อนหน้า

  • คลิกที่บรรทัดเนื้อเพลงเพื่อกระโดดไปยังช่วงนั้น
  • คลิกที่แถบเวลาเพื่อ seek
  • เคอร์เซอร์และปุ่มจะซ่อนเองเมื่อไม่ขยับเมาส์ 3.5 วินาที
  • คีย์ลัดจะไม่ทำงานขณะพิมพ์ในช่องค้นหา / ช่องข้อความ


ฟีเจอร์
-------
  • พื้นหลังเป็นปกอัลบั้มเบลอสองชั้นที่เคลื่อนไหวช้าๆ และเฟดเปลี่ยนเมื่อเปลี่ยนเพลง
  • ปกอัลบั้มความละเอียดสูง (1400×1400) ย่อลงเล็กน้อยตอนหยุดเพลงแบบ Apple
  • เนื้อเพลงซิงก์ตามเวลา บรรทัดปัจจุบันสว่างและมี glow บรรทัดอื่นจางและเบลอตามระยะ
  • ถ้าไม่มีเนื้อเพลงหรือซ่อนเนื้อเพลง ปกอัลบั้มจะเลื่อนมาตรงกลางและใหญ่ขึ้น
  • ถ้ามีแต่เนื้อเพลงแบบไม่มีเวลา (plain) จะเลื่อนตามสัดส่วนความยาวเพลง
  • ฟอนต์ Inter (อังกฤษ) + Anuphan (ไทย) ฝังมากับส่วนขยาย ไม่ต้องติดตั้งเพิ่ม
  • สกินหน้าเว็บปกติ: ธีมมืด ฟอนต์อ่านง่าย ปกอัลบั้มมุมโค้ง focus ring ชัดสำหรับใช้คีย์บอร์ด/รีโมต
  • เลย์เอาต์ออกแบบที่ 1920×1080 และสเกลได้ถึง 4K


ข้อจำกัด
--------
  • เนื้อเพลงมาจาก LRCLIB (https://lrclib.net) ซึ่งเป็นฐานข้อมูลชุมชน
    เพลงไทยหลายเพลงอาจยังไม่มีเนื้อเพลง หรือมีแต่แบบไม่ซิงก์เวลา
    เนื้อเพลงบางเพลงอาจคลาดเวลาเล็กน้อยถ้าเวอร์ชันไม่ตรงกับใน Apple Music
  • ส่วนขยายอ่านข้อมูลจากหน้าเว็บของ Apple (MusicKit ที่เว็บโหลดเอง, Media Session, <audio>)
    ถ้า Apple เปลี่ยนโครงสร้างเว็บ บางส่วนอาจหยุดทำงาน (ออกแบบให้หน้าเว็บไม่พังในกรณีนั้น)
  • สกินหน้าเว็บปกติใช้ selector แบบ attribute / data-testid เพื่อให้ทนการเปลี่ยนแปลง
    แต่บางส่วนของเว็บ Apple อยู่ใน Shadow DOM ของเขาเอง ซึ่ง CSS จากภายนอกเข้าไปแต่งไม่ได้
  • ปุ่ม Z ใช้ระบบซูมของเบราว์เซอร์ (เหมือนกด Ctrl + / Ctrl -) ซึ่งเบราว์เซอร์จำค่าแยกตามเว็บไซต์ด้วย
  • การเข้าเต็มจอต้องเกิดจากการกดปุ่ม/คลิกของผู้ใช้ (ข้อกำหนดของเบราว์เซอร์)
  • พื้นหลังเบลอใช้ GPU ถ้าเครื่องช้ามาก ให้เปิด "Use graphics acceleration" ในการตั้งค่าเบราว์เซอร์
  • ต้องใช้ Chrome / Edge เวอร์ชัน 111 ขึ้นไป


ไฟล์ในโฟลเดอร์
--------------
  manifest.json   ตั้งค่าส่วนขยาย
  page.js         ทำงานในหน้าเว็บ (MAIN world): อ่านสถานะเพลง, UI โหมดทีวี (Shadow DOM), คีย์ลัด
  bridge.js       ตัวกลาง (ISOLATED world): โหลดฟอนต์ และส่งข้อความระหว่างหน้าเว็บกับ background
  background.js   service worker: ค้นหาเนื้อเพลงจาก LRCLIB และเก็บ cache
  skin.css        สกินหน้าเว็บปกติ
  fonts/          Inter และ Anuphan (SIL Open Font License 1.1 — ดู LICENSE-*.txt)


ความเป็นส่วนตัว
---------------
  ส่วนขยายส่งเฉพาะชื่อเพลง ศิลปิน อัลบั้ม และความยาวเพลง ไปที่ lrclib.net เพื่อค้นหาเนื้อเพลง
  ไม่มีการเก็บหรือส่งข้อมูลบัญชี Apple ของคุณ
